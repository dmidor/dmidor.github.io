Kim jesteśmy

Farma AI to prywatna, niekomercyjna automatyzacja domowa, uruchomiona na serwerze należącym do jej właściciela i używana wyłącznie przez niego. Aplikacja nie ma innych użytkowników i nie przyjmuje rejestracji. Administratorem danych jest właściciel aplikacji, kontakt: dmidor@gmail.com.

Jakie dane są przetwarzane

Aplikacja uzyskuje dostęp wyłącznie do konta Google swojego właściciela, po jego wyraźnej zgodzie, w zakresie gmail.readonly (odczyt poczty i ustawień). Zakres ten nie pozwala na wysyłanie, usuwanie ani modyfikowanie wiadomości.

Z poczty odczytywane są:

  • metadane wiadomości: nadawca, data, temat,
  • treść wiadomości rozpoznanych jako rachunki, faktury i potwierdzenia płatności,
  • załączniki takich wiadomości (np. faktury PDF).

Z tych danych wydobywane są: data płatności, kwota, wystawca i tytuł. Aplikacja celowo nie zapisuje numerów kont, numerów kart, salda rachunku ani danych uwierzytelniających.

W jakim celu

Wyłącznie po to, by prowadzić domowy budżet właściciela: rozpoznawać wydatki, pilnować terminów płatności i przygotowywać zestawienia. Dane nie są wykorzystywane do profilowania, reklamy ani podejmowania decyzji wobec innych osób.

Komu dane są przekazywane

Dane nie są sprzedawane, wymieniane ani udostępniane osobom trzecim w celach własnych tych osób. Istnieje jednak jedno przekazanie, które ujawniamy wprost, bo jest nieodłączną częścią działania aplikacji:

  • Dostawcy modeli językowych. Aby zaklasyfikować wiadomość jako rachunek i odczytać z niej kwotę, jej treść jest przesyłana do zewnętrznego interfejsu modelu językowego (obecnie OpenRouter jako pośrednik oraz dostawca wybranego modelu). Dane są tam przetwarzane w celu udzielenia odpowiedzi, zgodnie z politykami tych dostawców.

Gdzie dane są przechowywane

Wyniki przetwarzania (zapisy budżetu, pobrane faktury) przechowywane są na prywatnym serwerze właściciela w Unii Europejskiej, dostępnym tylko dla niego. Aplikacja przechowuje token odświeżania OAuth, który służy wyłącznie do ponawiania dostępu do poczty właściciela.

Jak długo

Zapisy budżetu są przechowywane tak długo, jak długo właściciel ich potrzebuje; usuwa je samodzielnie. Dane znikają trwale wraz z wyłączeniem serwera lub usunięciem wolumenu z danymi.

Wycofanie zgody

Dostęp aplikacji do konta Google można odebrać w każdej chwili i ze skutkiem natychmiastowym na stronie myaccount.google.com/permissions. Po odebraniu zgody aplikacja traci możliwość odczytu poczty.

Zgodność z polityką Google

Wykorzystanie danych uzyskanych z interfejsów Google podlega Google API Services User Data Policy, w tym wymogom ograniczonego użycia (Limited Use). Dane z Gmaila są używane wyłącznie w celu opisanym wyżej i nie są używane do trenowania modeli uogólnionych.

Zmiany

Zmiany tej polityki będą publikowane na tej stronie wraz z nową datą obowiązywania.

English summary

Farma AI is a private, non-commercial home automation run by and for a single person — its owner. It is not a public service and has no other users.

It accesses only the owner's own Google account, with their explicit consent, using the gmail.readonly scope. That scope does not permit sending, deleting or modifying mail. It reads message metadata, and the content and attachments of messages identified as bills, invoices and payment confirmations, in order to maintain the owner's household budget and track payment due dates. It deliberately does not record bank account numbers, card numbers or balances.

Data is not sold, traded or shared with third parties for their own purposes. One disclosed transfer is inherent to how the application works: message content is sent to an external large language model API (currently OpenRouter as an intermediary, plus the selected model provider) in order to classify the message and extract amounts. Processing results are stored on the owner's private server in the European Union.

Access can be revoked at any time, with immediate effect, at myaccount.google.com/permissions. Use of Google user data complies with the Google API Services User Data Policy, including the Limited Use requirements. Gmail data is not used to train generalized models.
